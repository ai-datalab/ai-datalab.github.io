Loaded files

Uses FinOps Open Cost and Usage Specification (FOCUS) columns, but you do not need to know the standard to use this dashboard. Basic structural checks only: this is not full certification. Invalid snapshots are rejected without changing the last good dataset.

Claude and OpenAI live billing connectors are not connected. API cost/usage, enterprise seats and cloud-hosted models have different billing sources; never count a reseller bill and a direct-provider bill for the same charge.

From a file to a trustworthy total

What the dashboard does with your data, and what it deliberately does not claim.

Keep the money intact

Billed and effective costs are summed with decimal arithmetic. Credits stay negative. Currencies are filtered separately, never added or converted.

Replace, don't double-count

Every import replaces this session's full snapshot. Include all partitions once. Repeated charge rows are preserved because the source format does not guarantee row uniqueness.

Missing is not zero

Token counters, models and workloads that a file does not supply show as "Not supplied". Days with no charges are not drawn as zero.

Ratios are blended

Cost per million tokens uses only rows that report every token counter. It mixes input, output and cache pricing, so it is not a model price benchmark.

Run-rate is not a forecast

Month-end figures extend the spend to date at a straight-line pace. They ignore weekends, launches and price changes.

Fabric comes next

The included Fabric loader uses the same parser to write a prototype Delta table. No workspace, export, Power BI model or scheduled ingestion has been deployed.

The AI scenario is synthetic: illustrative model-family labels, costs and usage, not actual rates or invoices. The multi-cloud scenario is also invented: made-up accounts, resources, tags and amounts, with public service and region names for readability. It is not provider pricing or billing data. Amounts display to two decimal places. Visual layout follows the DataHub App demo. No vendor endorsement.
